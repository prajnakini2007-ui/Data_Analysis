# Travel and Tourism Data Analysis
## About The Project
This Project performs Exploratory Data Analysis (EDA) on the Travel and Tourism Dataset using Python.
## Tools and Libraries
- Python 
- Pandas
- Numpy
- Matplotlib
- Jupyter Notebook
## Dataset
The dataset contains information about travel and tourism, including tourist destinations, traveler demographics, travel preferences, modes of transportation, accommodation types, travel expenses, trip duration, and tourist satisfaction.
## Analysis Performed
- Identified categorical and numerical columns.
- Checked missing values and duplicate records.
- Calculated mean, median, and mode for numerical columns.
- Identified outliers using the IQR method.
- Created histograms, bar charts, and box plots.
- Analyzed booking trends by month and year.
- Identified popular destinations, hotels, and transportation types.
- Examined correlations between trip cost, number of nights, discounts, and customer ratings.
## Conclusion
This project helped me understand data cleaning, statistical analysis, outlier detection, and data visualization using Python.
